## Projects

### SQLWhisper
A local app that turns plain-English questions into PostgreSQL queries. It connects to your own database, reads the table schemas, and uses a fine-tuned Qwen2.5-1.5B model to write the SQL.

- Fine-tuned with QLoRA on 543 examples covering joins, CTEs, subqueries, and window functions
- Built with Python, PyTorch, Hugging Face, FastAPI, and PostgreSQL
- [Repo](link)

### Back2You
A lost-and-found platform where users post lost and found items with photos.

- Built with React, Spring Boot, PostgreSQL, and AWS S3
- Includes user accounts with JWT authentication and image uploads
- [Repo](link)

### BuildLog
A full-stack blogging app with users, posts, and comments.

- Built with React, Node.js, Express, and PostgreSQL
- [Repo](link)

### F1 Standings
